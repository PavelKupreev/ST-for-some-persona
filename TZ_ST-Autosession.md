# Техническое задание: RPG-автосессия для SillyTavern

| Версия | Дата | Статус |
|---|---|---|
| 2.0 | 28.10.2026 | Утверждено |

## 1. Общие сведения

### 1.1 Описание проекта
Расширение для SillyTavern (ST), в котором от 1 до 10 персонажей из готовых карточек ST живут и разговаривают сами, а пользователь наблюдает и изредка направляет: даёт героям тайные микроцели и пишет записки мастеру. Есть три режима игры: «Без мастера» (персонажи просто общаются), «Приключение» (мастер-DM ведёт повествование, бросает кубики 5e и озвучивает NPC) и «Романтика 18+» (мастер-рассказчик без кубиков). Персонажей можно разделить на изолированные группы, которые не слышат друг друга. Пользователь может в любой момент сам сыграть за одного из персонажей и вернуть его ИИ. По кнопке Историк пишет летопись — художественный рассказ о том, что произошло, зачем и почему.

### 1.2 Тип проекта и контекст
- Пет-проект для себя, без дедлайна.
- MVP большой идеи из ТЗ «Мультиагентная RPG-система» v2.3. Оттуда взяты роли мастера и Историка, механика 5e, внешний рандомайзер и принцип изоляции знаний между агентами. Всё остальное — в копилке v2 (раздел 5.2).
- Код пишет Claude Code, пользователь проверяет.

## 2. Концепция
- **Проблема / желание:** групповой чат ST работает криво и бедно по функциям. Хочется не играть самому, а смотреть живую историю, где персонажи общаются друг с другом, у них есть свои цели, а мастер ведёт сюжет как в D&D.
- **Выбранная концепция и почему:** «Б. Автосессия», строится через этап «А. Ход по кнопке». Пользователь хочет смотреть, а не кликать — значит нужен авто-режим. Летопись — главная ценность для чтения.
- **Рассмотренные альтернативы:**
  - А «Ход по кнопке» — слишком мало для «смотрю и направляю»; используется как первый этап реализации.
  - В «v2.3 целиком» (Арбитр, игровые часы, шина, локации) — перебор для двух героев в одной сцене, Арбитр удваивает число запросов.
  - Групповой чат ST с авто-режимом — отвергнут пользователем: работает криво, нет нужных функций. Расширение ведёт свой цикл ходов.
- **Ключевые решения:**
  - Каждый агент получает свой промпт, собранный расширением — так тайные цели и мысли не утекают ко второму герою.
  - Кубики бросает код, не модель.
  - Порядок ходов не по кругу: следующего выбирает мастер, с настраиваемой долей случайности.
- **Аналоги и источники:**
  - [Group Chats — документация ST](https://docs.sillytavern.app/usage/core-concepts/groupchats/) — авто-режим группового чата (не используется).
  - [Writing Extensions — документация ST](https://docs.sillytavern.app/for-contributors/writing-extensions) — `generateRaw`, `getContext`, хранение настроек.
  - ТЗ «Мультиагентная RPG-система» v2.3 пользователя.

## 3. Цели и критерии успеха
- **Цель:** рабочий прототип, который сам разыгрывает историю 1–10 героев (в одной или нескольких изолированных группах) и выдаёт летопись, приятную для чтения.
- **Критерии успеха:**
  1. Автосессия проходит 20 ходов подряд без поломок и ручного вмешательства.
  2. Герои не путают, кто есть кто, и не говорят за другого героя.
  5. Персонажи разных групп ни разу не получают реплик друг друга, кроме того, что передал мастер (проверка по логу промптов).
  3. Тайные цели, микроцели и мысли одного героя ни разу не попадают в промпт другого (проверка по логу промптов).
  4. По летописи понятно, что произошло, зачем и почему; летопись читается как художественный текст. Сами реплики в чате могут быть проще.
- **Кто принимает:** пользователь (субъективная оценка летописи + проверка пунктов 1–3).

## 4. Пользователи и роли
| Роль | Описание | Кол-во | Права |
|---|---|---|---|
| Пользователь | Автор, наблюдатель, режиссёр, при желании игрок | 1 | Всё: настройки, режим, старт, правка героев и мира, группы, микроцели, записки, остановка, игра за одного героя |
| Мастер | LLM-агент (дорогая модель), кроме режима «Без мастера» | 0–1 | Повествование, NPC, броски, выбор следующего, изменение статов, переходы между группами; видит всё |
| Герой | LLM-агент (дешёвая модель) или игрок | 1–10 | Только свои реплика, намерение, мысли; видит только своё и сцену своей группы |
| Историк | LLM-вызов по кнопке | 1 | Пишет летопись; видит всё |

## 5. Границы

### 5.1 Входит (MVP)
- Расширение ST, 1–10 героев из готовых карточек; одна общая сцена или до 5 изолированных групп.
- Три режима игры: «Без мастера», «Приключение», «Романтика 18+».
- Игра пользователя за одного персонажа с передачей обратно ИИ.
- Старт: промпт мира → карточка мира → выбор героев → генерация статов и целей → правка → запуск.
- Автосессия с мастером, свободным порядком ходов, кубиками 5e.
- Вмешательство: тайные микроцели, записки мастеру.
- Остановка: кнопка, лимит ходов, конец сцены.
- Летопись по кнопке и отдельная страница для её чтения.
- Две модели OpenRouter: для мастера и для героев.

### 5.2 Не входит (копилка v2)
- NPC как отдельные агенты с карточками, которые создаёт мастер (главная идея v2).
- Больше 10 героев.
- Автоматическое слияние групп по решению модели без мастера.
- Скрытие от игрока чужих групп и мыслей в чате (игрок видит весь чат).
- Игра пользователя за нескольких персонажей одновременно.
- Арбитр, игровые часы и дни, шина событий из v2.3.
- Перегенерация (свайп) хода.
- Мобильная версия.
- Перенос на сервер (Raspberry Pi).
- Техническая сводка для пользователя — заменена летописью.

## 6. Сценарии

### UC-01 Подготовка мира
- **Актор / Предусловия:** пользователь; расширение установлено, OpenRouter настроен, открыт новый чат.
- **Основной сценарий:**
  1. Пользователь пишет короткий промпт мира («фэнтези, драконы, волны чудовищ»).
  2. Мастер расширяет его в карточку мира.
  3. Пользователь правит и подтверждает.
- **Ошибки и альтернативы:** ошибка API → сообщение, промпт сохранён, можно повторить. Пустой промпт → кнопка неактивна.
- **Результат:** карточка мира сохранена в метаданных чата.

### UC-02 Подготовка героев
- **Актор / Предусловия:** пользователь; карточка мира готова.
- **Основной сценарий:**
  1. Пользователь задаёт число персонажей (1–10, без мастера 2–10) и отмечает столько же карточек ST, каждой назначает группу (по умолчанию все в A).
  2. Мастер по карточкам и миру генерирует для каждого: статы 5e и HP, глобальную цель из предыстории, стартовую микроцель.
  3. Пользователь правит всё и подтверждает.
  4. Пользователь пишет завязку сцены или оставляет поле пустым — тогда мастер придумывает её сам.
- **Ошибки и альтернативы:** число отмеченных карточек не равно заданному → «Старт» неактивен. Карточка на английском — нормально, игра идёт на языке из настроек. Битый JSON статов → сообщение, можно перегенерировать или заполнить вручную.
- **Результат:** состояние героев сохранено, можно запускать.

### UC-03 Автосессия
- **Актор / Предусловия:** пользователь нажал «Старт»; мир и герои готовы.
- **Основной сценарий:**
  1. Мастер описывает сцену и выбирает, кто действует дальше: герой 1, герой 2 или снова мастер.
  2. С вероятностью из настройки «случайность» код заменяет выбор мастера случайным.
  3. Ходит выбранный герой: реплика + намерение + скрытые мысли.
  4. Мастер описывает исход. Если нужен бросок, ставит метку, код бросает кубик, мастер дописывает исход по результату.
  5. Цикл повторяется, счётчик оставшихся ходов уменьшается.
- **Ошибки и альтернативы:**
  - Ошибка API или ответ не разобран → немедленная пауза и уведомление; «Продолжить» повторяет сорвавшийся ход.
  - Герой молчал N ходов подряд → его ход обязательный.
  - Пользователь нажал «Пауза» → текущая генерация завершается, новая не стартует.
  - Пользователь нажал «Стоп» → то же, сессия завершена до нового «Старта».
- **Результат:** ходы в чате, состояние обновлено.

### UC-04 Вмешательство
- **Актор / Предусловия:** пользователь; автосессия идёт или на паузе.
- **Основной сценарий:**
  1. Пользователь выбирает героя и пишет микроцель **или** пишет записку мастеру.
  2. Микроцель попадает в промпт этого героя и мастера, начиная со следующего хода; записка — в промпт мастера на ближайший его ход.
- **Ошибки и альтернативы:** микроцель заменяет предыдущую; второй герой её не видит.
- **Результат:** поведение героя или мастера меняется в следующих ходах.

### UC-05 Остановка
- **Основной сценарий:** автосессия останавливается при любом из условий:
  1. Нажата кнопка «Стоп».
  2. Счётчик ходов дошёл до 0.
  3. Мастер пометил конец сцены и включён переключатель «стоп в конце сцены».
- **Результат:** пауза, сообщение о причине остановки, состояние сохранено.

### UC-06 Летопись
- **Актор / Предусловия:** пользователь; есть ходы после последней главы.
- **Основной сценарий:**
  1. Пользователь нажимает «Летопись».
  2. Историк получает все ходы с последней главы, включая мысли и цели, и пишет новую главу.
  3. Глава добавляется в конец летописи; пользователь читает её на отдельной странице.
- **Ошибки и альтернативы:** новых ходов нет → кнопка неактивна. Ошибка API → сообщение, предыдущие главы не тронуты.
- **Результат:** новая глава в летописи.

### UC-07 Продолжение после перерыва
- **Основной сценарий:** пользователь открывает тот же чат (после перезагрузки ST) → расширение подхватывает мир, героев, счётчик и летопись → «Продолжить».

### UC-08 Группы и переходы
- **Актор / Предусловия:** пользователь или мастер; герои разделены на группы (A–E).
- **Основной сценарий:**
  1. Мастер ведёт одну группу за раз (группа в фокусе): его ход пишется в историю только этой группы.
  2. Фокус переходит к другой группе, когда мастер называет её (`[NEXT: master B]`) или героя из неё, а также когда герой другой группы давно молчит или выбран случайно. Переход всегда идёт через ход мастера для новой группы.
  3. Весть между группами передаёт только мастер, событием в сцене другой группы (гонец, письмо, слух).
  4. Мастер переводит героя в другую группу или уводит из сцены блоком STATE; пользователь может сделать то же в профиле героя.
- **Ошибки и альтернативы:** ушедший из сцены герой заморожен до возвращения; если все герои заморожены — сессия на паузе.
- **Результат:** группы живут параллельно и ничего не знают друг о друге напрямую.

### UC-09 Игра за персонажа
- **Актор / Предусловия:** пользователь; персонажи готовы.
- **Основной сценарий:**
  1. В меню 🎲 пользователь выбирает «Играть за: X».
  2. Автосессия идёт сама, пока очередь не дойдёт до X, затем встаёт на паузу «Ваш ход за X».
  3. Пользователь пишет ход в поле ввода ST и нажимает «✍️ Сходить за X»; сообщение уходит в чат от имени X, сессия продолжается.
  4. «Играть за: никого» возвращает X ИИ; выбор другого персонажа Y возвращает X ИИ и запускает автоход до хода Y.
- **Результат:** игрок участвует в истории наравне с ИИ-героями.

### UC-10 Выбор режима
- **Основной сценарий:** до старта пользователь выбирает режим на вкладке «Игра»; интерфейс показывает только нужное режиму (мир и листы — для «Приключения» и «Романтики»).
- **Ошибки и альтернативы:** во время идущей сессии режим не меняется.

## 8. Данные
Состояние игры хранится в метаданных чата ST (`chatMetadata`), настройки расширения — в настройках ST (`extensionSettings`).

| Сущность | Поля |
|---|---|
| Мир | исходный промпт, сеттинг, правила (3–5), эпоха, тон, уровень силы |
| Герой (×1–10) | id карточки ST, имя, STR…CHA, HP (текущий/максимум), уникальные способности (название, описание, стат, уровень, применения), инвентарь, глобальная цель, микроцель, отношения (романтика), группа (или заморожен), история пребывания в группах, счётчик молчания |
| Ход | номер, автор (`master` / `hero1`…`hero10`), группа, ход игрока (да/нет), видимый текст, намерение, мысли, броски, изменения статов, флаг конца сцены |
| Память | сжатые старые ходы: общая часть по группам + отдельно мысли каждого героя |
| Летопись | главы: номер, заголовок, диапазон ходов, текст |
| Сессия | режим, число персонажей, статус (не начата / идёт / пауза / стоп), оставшиеся ходы, записка мастеру, группа в фокусе, персонаж игрока, ожидание хода игрока |

- Объём: десятки–сотни ходов на чат.
- Бэкапы: средствами ST (бэкап чатов).
- Ключ OpenRouter не хранится в метаданных чата и не попадает в чат.

## 9. Интерфейс
- **Главная панель** в строке ввода чата ST (FR-28): меню 🎲 слева, счётчик и кнопки хода справа.
- **Страница игры** (FR-27) в отдельной вкладке браузера с вкладками: «Персонажи», «Игра» (мир, герои, старт), «Летопись», «Настройки».
- **В чате:** сообщения мастера и героев, метка группы (если групп больше одной), спойлер мыслей, плашки бросков, системные сообщения об остановке и ошибках.
- Язык интерфейса — русский `[Допущение]`.

## 10. Интеграции и окружение
- SillyTavern последней стабильной версии `[Допущение]`, локально на ПК пользователя.
- Расширение на JavaScript по официальному шаблону ST.
- LLM: OpenRouter, две модели — дороже для мастера и Историка `[Допущение: Историк на модели мастера]`, дешевле для героев.
- Способ вызова двух разных моделей (через бэкенд ST с подменой модели или напрямую в API OpenRouter) определяется на техническом спайке (PLAN 1.2).
- Кубики: `crypto.getRandomValues`, без участия модели.

## 12. Сроки и организация
- Сроки: без дедлайна, по вечерам.
- Исполнитель: Claude Code пишет код, пользователь проверяет и тестирует.
- Этапы: каркас и спайк → ход по кнопке (А) → старт игры → автосессия (Б) → вмешательство → статы и память → летопись → приёмка.
- Передаётся: git-репозиторий расширения с README по установке.

## 13. Критерии приёмки
- **FR-01/02:** Дано промпт «фэнтези, драконы». Когда нажата «Расширить». Тогда появляется карточка мира со всеми полями, и любое поле можно отредактировать.
- **FR-03:** Дано число персонажей 3. Когда отмечено 2 или 4 карточки. Тогда «Старт» неактивен; при 3 — активен. Дано режим «Без мастера», число 1. Тогда поле не даёт меньше 2.
- **FR-04/05:** Дано 2 карточки. Когда нажата «Сгенерировать». Тогда у каждого героя 6 статов 1–20, HP, 1–2 уникальные способности, глобальная цель, микроцель, все поля редактируются.
- **FR-07:** Дано идёт сессия. Когда нажата «Пауза». Тогда новых генераций после текущей нет; «Продолжить» возобновляет с того же места.
- **FR-08/09:** Дано случайность 0 %. Тогда следующий всегда тот, кого назвал мастер. Дано 100 % — выбор случайный (видно по логу).
- **FR-10:** Дано порог 4, герой 2 молчал 4 хода. Тогда следующий ход — героя 2.
- **FR-11/16:** Ход героя показывает реплику и намерение, мысли — в свёрнутом спойлере.
- **FR-12/18 (NFR-01):** Дано у героя 1 микроцель «украсть ключ». Тогда в логе промптов героя 2 за 20 ходов нет ни этой фразы, ни мыслей героя 1.
- **FR-13/14:** Дано мастер поставил `[ROLL d20 DEX DC12]`, DEX героя 14. Тогда в чате плашка с бросок+2 против 12 и верным ✅/❌; натуральная 1 — ❌ при любом модификаторе.
- **FR-13 (частота проверок):** Дано частота 0 %. Тогда за 10 ходов ни одной плашки броска. Дано 100 %. Тогда после каждого действия героя плашка броска.
- **FR-15:** Дано мастер нанёс 5 урона. Тогда HP героя в профиле уменьшилось на 5. Дано частота проверок 100 %, 15 ходов с опасными действиями. Тогда хотя бы один опасный провал снимает HP.
- **FR-31:** Дано у героя «Огненный шар» уровня 1, INT 16, применён 2 раза. Когда мастер поставил `[ROLL d20 Огненный шар DC14 hero1]`. Тогда плашка «Огненный шар (INT, ур. 1): d20+4», после неё «✨ Огненный шар — уровень 2!», в панели «ур. 2 · 3/7»; следующий бросок способности — d20+5.
- **FR-19:** Дано записка «пусть пойдёт дождь». Тогда в ближайшем ходе мастера есть дождь, а в промптах героев нет текста записки.
- **FR-20:** Дано N = 10. Тогда счётчик идёт 10 → 0, при 0 сессия останавливается с сообщением. Дано осталось 13 из 20, N изменён на 5. Тогда счётчик 5/5.
- **FR-27/28:** Дано открыт чат ST. Тогда над левыми иконками строки ввода есть 🎲 с меню из FR-28, над правыми — счётчик и кнопки хода. Когда нажата «Страница игры». Тогда открывается вкладка браузера с «Персонажи», «Игра», «Летопись», «Настройки»; после F5 в ST вкладка подключается снова.
- **FR-21:** Дано переключатель включён, мастер пометил конец сцены. Тогда сессия на паузе с причиной «сцена завершена».
- **FR-22:** Дано неверный ключ API. Тогда пауза после первой ошибки, уведомление с причиной, без повторов.
- **FR-23/24:** Дано 15 ходов. Когда нажата «Летопись». Тогда появляется глава в конце летописи, от третьего лица, объясняет мотивы героев; прошлые главы без изменений.
- **FR-30 (NFR-08):** Дано сессия на ходе 7. Когда ST перезагружен и чат открыт. Тогда статы, счётчик, микроцели и летопись на месте, «Продолжить» идёт с хода 8.
- **FR-33:** Дано режим «Без мастера», 3 персонажа в группе A. Тогда реплики идут по кругу 1 → 2 → 3, мира, листов и плашек нет. Дано старый чат с RPG. Тогда он открывается в «Приключении».
- **FR-34/35 (NFR-01):** Дано Мира и Арен в группе A, Grokk в B. Тогда за 20 ходов в промптах Grokk нет реплик Миры и Арена, а в промптах Миры нет реплик Grokk; весть из A в B появляется только в тексте мастера для B. Дано мастер написал `[STATE {"hero3": {"leave": true}}]`. Тогда Grokk заморожен: не ходит и не выбирается, пока его не вернут в группу.
- **FR-36:** Дано «Играть за: Мира», идёт автосессия. Тогда сессия встаёт на ход Миры с «Ваш ход за Миру»; после «✍️ Сходить» текст в чате от Миры, сессия идёт дальше. Когда выбран «Играть за: Арен». Тогда Мира ходит сама, сессия идёт до хода Арена.
- **FR-37:** Дано режим «Романтика», 2 героя. Тогда в листах нет статов и HP, есть отношения; за 10 ходов ни одной плашки броска; изменение отношения из блока STATE видно в профиле.
- **FR-32:** Дано «без смерти», у Миры HP 0. Тогда Мира не ходит и не выбирается, пока мастер не промотает ≥ 24 игровых часов, затем «приходит в себя» с HP ≥ 1. Дано «со смертью». Тогда Мира больше не ходит; когда пали все герои, сессия остановлена с причиной «все герои погибли».

## 14. Риски
| Риск | Вероятность | Влияние | Мера |
|---|---|---|---|
| ST не даёт удобно вызывать две разные модели | Средняя | Высокое | Спайк в начале (PLAN 1.2); запасной вариант — прямой вызов API OpenRouter |
| Модели нарушают формат ответа (реплика/намерение/мысли, JSON статов) | Высокая | Среднее | Строгий формат в промпте, терпимый парсер; при провале — пауза (FR-22) |
| Герой говорит за другого героя или за мастера | Средняя | Среднее | Промпт с запретом + обрезка текста по чужим именам |
| Утечка тайного через историю чата | Средняя | Высокое | Мысли хранятся отдельно от видимого текста; NFR-01 + лог промптов |
| Мастер всегда выбирает одного героя | Средняя | Низкое | Случайность (FR-09) + защита от молчания (FR-10) |
| История зацикливается, сюжет не движется | Средняя | Среднее | Глобальные цели в промпте мастера, записки мастеру |
| Контекст переполняется в длинных играх | Высокая | Среднее | Сжатие памяти (FR-26) |
| Обновление ST ломает расширение | Средняя | Среднее | Использовать только `getContext()` и документированные функции |

## 15. Допущения
- Статы, цели и микроцели генерирует мастер, пользователь правит.
- Язык игры — настройка, по умолчанию русский; карточки RU или EN.
- Старые ходы невидимо сжимаются, чтобы не переполнять контекст; отдельной сводки для пользователя нет.
- Все NPC озвучивает мастер.
- Защита от молчания: порог по умолчанию 4 хода.
- Историк работает на модели мастера.
- Задержка между ходами по умолчанию 3 с.
- Завязку сцены можно оставить пустой — мастер придумает.
- SillyTavern последней стабильной версии, локально.
- Интерфейс расширения на русском.
- Микроцель новой заменяет старую (по одной на героя).
